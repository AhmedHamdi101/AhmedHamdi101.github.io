# Architecture

Astro statically renders every page, keeping runtime JavaScript limited to the mobile navigation, theme preference, and optional filters. File-based routes provide `/research`, `/publications`, `/updates`, `/notes`, `/cv`, plus generated project and note pages.

`src/config/site.ts` is the identity source of truth. `src/content.config.ts` validates Markdown/YAML collections. Components are intentionally small presentation units; layouts own shared metadata and navigation. CSS custom properties centralize the visual system and support light/dark themes. Semantic landmarks, native controls, focus styles, contrast-conscious colors, and reduced-motion support are baseline accessibility choices.

SEO metadata is generated by `BaseLayout`; `@astrojs/sitemap` emits a sitemap and `robots.txt.ts` points crawlers to it. The GitHub Actions workflow builds static output and deploys it to Pages. Dependencies are limited to Astro, its official checker/sitemap integrations, TypeScript, and Prettier.
